VARIABLES (Auto-filled from user's data):

R Curly Braces: Use {{ '{{' }} {{ '}}' }} for if/else/loops
if (x > 0) {{ '{{' }} print("yes") {{ '}}' }}
"Column 'X' not found"
Why: Hardcoded column name instead of placeholder
Fix: Use {y_var} or {group_var} instead
"unexpected '{' in code"
Why: Single braces conflict with placeholders
Fix: Use DOUBLE braces: {{ '{{' }} code {{ '}}' }}
"object 'data' not found"
Why: Missing data loading step
Fix: Add {data_loading} after {package_helper}
"arguments have different lengths"
Why: Data in WIDE format, test needs LONG format
Fix: Add reshape code (see Data Formats tab)
WIDE Format (each condition is a column): 
Subject | Time1 | Time2 | Time3
A       | 10    | 15    | 20
B       | 12    | 18    | 22
LONG Format (one row per observation): 
Subject | Condition | Value
A       | Time1     | 10
A       | Time2     | 15
A       | Time3     | 20
Repeated measures tests need LONG format!
Add this reshape code: 
num_cols <- sapply({data}, is.numeric)
if (sum(num_cols) > 2) {{ '{{' }}
  data_long <- {data} %>%
    pivot_longer(cols = where(is.numeric),
      names_to = "condition", values_to = "value")
{{ '}}' }}

Generate an R code template for [TEST NAME] statistical test.

CRITICAL REQUIREMENTS:
1. Start with {package_helper} on first line
2. Use ensure_package("pkg") for each package
3. Use {data_loading} to load data
4. Use these EXACT placeholders (don't replace them):
   - {data} for the dataframe
   - {y_var} for outcome variable
   - {x_var} for predictor variable
   - {group_var} for grouping variable
   - {subject_var} for subject ID (repeated measures)

5. For if/else/loops, use DOUBLE braces:
   if (x > 0) {{ '{{' }} print("yes") {{ '}}' }}

6. For repeated measures, add auto-reshape:
   num_cols <- sapply({data}, is.numeric)
   if (sum(num_cols) > 2) {{ '{{' }}
     data_long <- {data} %>%
       pivot_longer(cols = where(is.numeric),
         names_to = "condition", values_to = "value")
   {{ '}}' }}

7. Include: assumption checks, effect size, ggplot2 visualization
8. Print results with cat() and print()
